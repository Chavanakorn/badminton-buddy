# 🏸 Badminton Buddy

เว็บแอปสำหรับสุ่มทีมแบดมินตันอัตโนมัติ

## ✨ ฟีเจอร์
- เพิ่ม/ลบสมาชิก (บันทึกใน localStorage)
- สุ่มจับคู่ทีมอัตโนมัติ
- รองรับ Responsive Design

## 📁 โครงสร้างโปรเจค
```
badminton-buddy/
├── index.html      # HTML structure
├── css/
│   └── styles.css  # All styles
├── js/
│   └── app.js      # Application logic
└── README.md
```
